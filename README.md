# Учебный трекер оценок (Grading System for Students & Lecturers)

Объектная модель на Python для учёта оценок в учебном процессе: студенты ставят оценки лекторам за лекции, ревьюеры — студентам за домашние задания. Система рассчитывает средние баллы, позволяет сравнивать участников и устойчива к некорректным данным.

## Возможности

- **Ролевая модель**: `Student`, `Lecturer`, `Reviewer`, базовый `Mentor`.
- **Выставление оценок**:
  - студенты оценивают лекции через `rate_lecture` только по курсам, которые изучают;
  - ревьюеры оценивают ДЗ через `rate_hw` только по прикреплённым курсам.
- **Валидация входных данных**:
  - проверка типов объектов;
  - проверка принадлежности курсов;
  - контроль диапазона оценок: принимаются только значения от 1 до 10.
- **Расчёт средних баллов**:
  - динамический расчёт среднего для каждого студента и лектора через `@property` (без хранения устаревшего значения);
  - расчёт среднего по конкретному курсу среди всех студентов или лекторов.
- **Сравнение участников** по среднему баллу: `==`, `<`, `>`.
- **Безопасность расчётов**: защита от деления на ноль, если оценок нет — возвращается `0.0`.

## Классы и их назначение

| Класс | Назначение |
| --- | --- |
| `Mentor` | Базовый класс для наставников: имя, фамилия, список прикреплённых курсов, метод `add_course`. |
| `Lecturer` | Лектор: получает оценки за лекции, считает средний балл, сравнивается с другими лекторами. |
| `Reviewer` | Ревьюер: ставит оценки студентам за ДЗ. Метод `rate_hw` реализован только здесь. |
| `Student` | Студент: курсы «в процессе» и «завершённые», словарь оценок, расчёт среднего, сравнение с другими студентами, выставление оценок лекторам. |

## Ключевые особенности реализации (важно для тестирования)

- **Динамический средний балл** через `@property` и общую функцию `calculate_average`. Исключает рассинхронизацию состояния — частую причину flaky-тестов.
- **Единая логика расчёта** в `calculate_average` — удобная цель для автотестов.
- **Валидация на входе** в методах `rate_lecture` и `rate_hw`: проверка типов через `isinstance`, принадлежности курсов, диапазона 1–10. Удобно покрывать негативными тест-кейсами.
- **Корректная обработка «пустых» данных**: если оценок нет, возвращается `0.0` вместо ошибки деления на ноль.
- **Проверка типов в методах сравнения** (`__eq__`, `__lt__`, `__gt__`): если передан объект другого типа, возвращается `False` — корректная работа операторов без падения.
- **Демонстрационный код вынесен в `demo.py`**: логика классов отделена от примеров использования, классы можно импортировать в тесты (pytest) без побочных эффектов.
- **Docstrings на всех классах и методах**: каждый публичный метод и класс описаны — это документация, которая помогает ревьюеру и автотестам.

##CI/CD (GitHub Actions)
Пайплайн запускается автоматически при каждом `push` и `pull request` в ветку `main`. Последовательность шагов:

- Checkout — клонирует код в чистую среду (Ubuntu).
- Setup Python 3.13 — устанавливает Python и кэширует `pip`.
- Install dependencies — ставит пакеты из `requirements.txt` (`pytest`, `pylint`, `pytest-cov`).
- Run pylint — проверяет код на стиль и потенциальные ошибки. Если есть замечания — пайплайн падает.
- Run pytest with coverage — запускает тесты и считает покрытие. Если хотя бы один тест падает — пайплайн падает.
- Зелёный пайплайн = код прошёл линтер, все тесты зелёные, покрытие посчитано.

Структура репозитория
Файл / папка | Назначение
| --- | --- |
| `grading_system.py` | Основная логика: классы Mentor, Lecturer, Reviewer, Student и утилиты (расчёт средних, валидация). |
| `demo.py` | Демонстрационный скрипт: создание объектов, выставление оценок, вывод результатов. |

| `requirements.txt` | Зависимости проекта: pytest, pylint, pytest-cov. |
| `.github/workflows/` | Пайплайны CI (GitHub Actions): запуск линтера, тестов и сбор покрытия. |
| `.gitignore` | Исключает из репозитория временные файлы: venv/, .coverage, __pycache__/ и др. |

## Пример использования

```python
from grading_system import Student, Lecturer

student = Student('Ольга', 'Алёхина', 'Ж')
student.courses_in_progress.append('Python')

lecturer = Lecturer('Иван', 'Иванов')
lecturer.courses_attached.append('Python')

student.rate_lecture(lecturer, 'Python', 8)

print(student)                  # Информация о студенте
print(lecturer)                  # Информация о лекторе
print(lecturer.average_grade)   # Динамически рассчитанный средний балл
```
### Полный демо-скрипт с созданием объектов и выводом — в файле demo.py.

## Быстрый старт
### 1. Клонируй репозиторий
```bash
git clone <ссылка-на-репозиторий>
cd grading-system
```
### 2. Создай виртуальное окружение и установи зависимости
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```
### 3. Запусти линтер (pylint)
```bash
pylint grading_system.py
```
Ожидаемый результат: 10.00/10, без ошибок с ненулевым кодом выхода.

### 4. Запусти автотесты с покрытием
```bash
pytest tests -v --cov=grading_system.py --cov-report=term
```
В выводе будет процент покрытия и отчёт по тестам.

### 5. Запусти демо-пример
```bash
python demo.py
```
